The built-in preview's copy (docs/design/20261028_05_BINARY_FILES_PLAN.md,
decision 10, and its 23:00 and 23:48 EDT amendments), compiled into the
app at build time with every other file in `copy/`, in the same layout:
one object tagged Copy per piece, its head the key the code names, in
capitals, as `copy::<KEY>`. The `preview_*` keys and the agent view's ⋮
item **Show uncommitted changes** are here.

The preview (`src/preview/`) draws these as plain text. A refusal's line
is the daemon's code's own (libflankr_blob's `Code::line`), not copy.

The ✕ at the left of the title bar; its label is for accessibility.
